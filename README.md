# Customer Segmentation Project (RFM Analysis & Clustering)

Built a customer segmentation model using RFM (Recency, Frequency, Monetary) analysis
on transactional data.

- Engineered customer-level features and applied rule-based segmentation to identify
  high-value and low-engagement customers
- Implemented K-means clustering to uncover data-driven customer groups based on
  behavioural patterns
- Analysed customer behaviour to generate actionable, data-driven recommendations for
  retention and targeted marketing strategies

**Tools:** Python, Pandas, NumPy, Scikit-learn, Matplotlib/Seaborn

Originally developed and published on [Kaggle](https://www.kaggle.com/code/siripiruntans/customer-segmentation-project-rfm-analysis).
